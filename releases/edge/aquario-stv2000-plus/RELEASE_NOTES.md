## Edge v0.2.0 — Aquario STV-2000 Plus 4

Primeiro build de produção (sideload) para o smart box **Aquario STV-2000 Plus 4**.

### Compatibilidade
- Android 10 (API 29)+
- ARM (`armeabi-v7a` / `arm64-v8a`)
- Touchscreen / Leanback opcionais

### API
`https://api.lede.tv.br/api`

### Instalação
Instalação manual — ative fontes desconhecidas no box e abra o APK.  
Guia: `releases/edge/aquario-stv2000-plus/README.md`
